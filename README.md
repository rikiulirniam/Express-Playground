## Instalation 
1. make a copy from <code>.env.example</code> 
```.env
MONGODB_URI="mongodb://localhost:27017/db_items"

APP_PORT=3000


```

2. install dependency
```bash
    npm install
```

3. run project
```bash
    npm run dev
```
